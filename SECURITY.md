# Security

Report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/geovicco-dev/bhoonidhi-explorer/security/advisories/new),
not in a public issue. Include the steps to reproduce it and what an attacker
could do with it. You will get a reply within a week.

Bhoonidhi Explorer holds no user accounts and no Bhoonidhi credentials: the
downloads it hands off run on the user's own machine. What it does hold is
each browser's saved conversations, keyed by an anonymous id kept in that
browser.
